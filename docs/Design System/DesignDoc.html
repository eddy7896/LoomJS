01Principles

A tool that hides its own programming

Every decision serves one idea: a designer should never feel they left the canvas. Code becomes cards, syntax becomes wires, and the compiler stays out of sight.

P1

Design-first, always

The artboard is home. Logic is generated from what you draw, then shown as cards you can open — never as a wall of text you must write.

P2

One calm surface

Soft white panels, a single warm red accent, generous radius and hairline borders. Nothing shouts; structure comes from spacing, not heavy rules.

P3

Color means type

Each node category owns one hue. Color is functional, never decorative — you read a graph by its colors before you read a single label.

P4

Legible by default

Archivo for interface, JetBrains Mono for anything that is code or data. Ports, wires and states follow one consistent grammar across every view.

02Logo & mark

The loom mark

Three vertical warp threads with a single red weft curving through them — the interface (the grid) and the woven-in system (the thread). The mark reads at 20px and up.

The Readable Grey Rule

Ink 3 (#868D97) measures 3.1:1 on canvas and 3.3:1 on panel. It is not a text colour on light surfaces. Metadata, annotations, port types and placeholders take Ink 2 (#4B5058, 7.8:1). Ink 3 survives only on rules, dots and other non-text marks. On the ink fold, muted (#9AA1AA) clears 6.6:1 and is safe for text.

08Brand surface

The page is a canvas

The studio and the landing page are one register apart. In the studio, design serves the work. On the landing page, design is the work, and the strongest thing loomJS can show a visitor is its own artefact. So the marketing page is built out of the product’s primitives: paper ground, dot grid, sheets that float, node cards, and wires that actually connect the things they touch.

The Working Surface Rule

The dot grid runs the full document and never stops. Sections are artboards and node clusters placed on it, not boxes stacked in a column. If a section could be lifted onto any other landing page unchanged, it is not carrying the brand.

The Honest Wire Rule

A wire on the brand surface obeys the same grammar as a wire in the graph: it runs between two things that are genuinely connected, and it takes the colour of the port it leaves. Wires are never decoration, never ambient, never drawn to fill space.

The one recurring device

Closed beta · V1 in development

A short mono annotation over a 28px rule. It appears once or twice per section and is placed differently every time: above a heading, in the right margin, under a diagram. A tracked uppercase kicker repeated over every section heading is AI scaffolding, not a system. The numbered eyebrows in this document are a documentation device and do not transfer to the brand surface.

Composition

  • Asymmetric and left-aligned. No centred stacks.
  • Section rhythm varies: dense datasheet rows next to open paper.
  • One dominant idea per fold, and one dark fold for the language.
  • Motion is a single orchestration: reveals release per section, wires draw themselves once. Nothing loops.

Do

  • Show the artefact. Artboards, node cards, generated code and file paths are the page’s imagery.
  • Spend the red once per screen, on the one action.
  • State what V1 does not do. The honest column is a differentiator, not a liability.
  • Draw structure with hairlines; keep the artboard double-shadow for things that genuinely float.

Don’t

  • Numbered kickers or tracked uppercase labels as section grammar.
  • Grids of identical cards with a rounded icon square above every heading.
  • Ambient glow blobs, gradient washes, sparkle icons, or any AI-product cue. loomJS compiles; it does not guess.
  • Glassmorphism. The one blurred surface that ever shipped here was the old floating nav, and it is gone.
  • Category hues on chrome, badges, or syntax highlighting. Colour on the brand surface means exactly what it means in the graph.
